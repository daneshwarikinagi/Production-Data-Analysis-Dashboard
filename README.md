# Production Data Analysis Dashboard

## 📊 Project Overview

A Python and Streamlit-based dashboard developed for **production data analysis and reporting**.

The dashboard helps users upload Excel/CSV production data, analyze stage-wise Pass/Fail/Pending status, track Work in Progress (WIP), search battery records, and generate Excel reports.

## 🚀 Key Features

* Excel/CSV data upload
* Production data cleaning and processing
* Stage-wise Pass/Fail/Pending analysis
* WIP tracking
* Battery serial number search
* Date-wise production analysis
* Work order filtering
* Production data visualization
* Excel report generation
* Battery history tracking

## 🛠️ Technologies Used

* Python
* Pandas
* Streamlit
* Plotly
* OpenPyXL
* Microsoft Excel

## 📌 Production Stages

* Chassis
* Air Leak
* Insulation
* Calibration
* LAT
* Communication
* EOL
* PDI

## ▶️ How to Run

### 1. Clone the repository

```bash
git clone YOUR_GITHUB_REPOSITORY_LINK
```

### 2. Open the project

```bash
cd Production-Data-Analysis-Dashboard
```

### 3. Install requirements

```bash
pip install -r requirements.txt
```

### 4. Run the dashboard

```bash
streamlit run production_dashboard.py
```

The dashboard will open in your browser.
